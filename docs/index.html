Backend Bridge
Connect a deployed translator

`github.io` can host the frontend only. Real-time microphone translation still needs an `https://` backend with `wss://` websocket support.

A page on `https://username.github.io` cannot call plain `http://127.0.0.1:8000` because browsers block mixed content.

Architecture
How the full version works

Static web shell

The `docs/` site is what you publish to GitHub Pages. It handles the product story, demo mode, and the future backend connection UI.

FastAPI + WebSocket

The real app streams microphone audio to a Python backend, which segments speech and returns subtitle updates in near real time.

GPU translation

`faster-whisper` runs multilingual Whisper translation on the GPU, making `small` and `medium` practical options for laptop hardware.

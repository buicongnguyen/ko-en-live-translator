About

Local live speech translation

LiveTranslate AI is a focused web interface for translating speech between selected languages with a self-hosted GPU backend. The main page avoids long product text so users can concentrate on the live transcript and translation panes.

Two ways to use it

  • GitHub Pages demo: runs a simulated translation showcase in the browser.
  • Local GPU backend: streams microphone audio to your Windows PC over HTTPS/WSS.

Translation flow

  1. Select the source language in the top toolbar.
  2. Allow microphone access from the browser.
  3. Read source speech on the left and target translation on the right.
  4. Use the copy buttons to save either transcript.

Model notes

The backend uses faster-whisper with multilingual Whisper models. Whisper translates speech directly to English. For targets such as Vietnamese, use a second local text-translation model after speech transcription.

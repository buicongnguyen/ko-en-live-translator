About

Local live speech translation

LiveTranslate AI is a local-network web app for translating speech between selected languages with a GPU-backed speech model. The main page stays focused on the two pieces people need during a conversation: source transcript and target translation.

How it works

  1. The browser records microphone audio after permission is allowed.
  2. Audio streams to the local FastAPI server through WebSocket.
  3. The server segments speech and runs faster-whisper on the GPU.
  4. The page appends source text and target translation in real time.

Language support

The toolbar lets each browser session choose both source and target language. Whisper can translate speech directly to English. Other targets use a second text-translation model when enabled.

Hardware target

The recommended local server is an NVIDIA GPU PC. RTX 4080 Super can run larger models comfortably, while smaller laptop GPUs can use smaller models or int8 modes for lower latency.

Privacy shape

In the local-network setup, microphone audio goes from the browser to your own host PC. No cloud backend is required for the core translation service.

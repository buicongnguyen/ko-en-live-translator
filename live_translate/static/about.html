About

Local live speech translation

LiveTranslate AI is a local-network web app for translating speech into English with a GPU-backed Whisper model. The main page stays focused on the two pieces people need during a conversation: source transcript and English translation.

How it works

  1. The browser records microphone audio after permission is allowed.
  2. Audio streams to the local FastAPI server through WebSocket.
  3. The server segments speech and runs faster-whisper on the GPU.
  4. The page appends source text and English translation in real time.

Language support

The toolbar lets each browser session choose a source language such as Korean, Japanese, Chinese, Vietnamese, Spanish, French, or Auto detect. Translation output remains English.

Hardware target

The recommended local server is an NVIDIA GPU PC. RTX 4080 Super can run larger models comfortably, while smaller laptop GPUs can use smaller models or int8 modes for lower latency.

Privacy shape

In the local-network setup, microphone audio goes from the browser to your own host PC. No cloud backend is required for the core translation service.
